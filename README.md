# local_profile_analyzer
Утилита разработана в двух вариантах реализации: на языке Bash и на языке Python. Оба варианта предназначены для запуска в операционных системах семейства GNU/Linux и обеспечивают реализацию единого набора функциональных возможностей.

Минимальные версии совместимых интерпретаторов:

    Bash — 5.0;
    Python — 3.0.

Утилита предназначена для сбора, систематизации и анализа информации об учетной записи пользователя, его домашней директории, истории выполнения команд и запущенных процессах. Полученные данные позволяют оценить основные параметры учетной записи, использование дискового пространства, принадлежность файлов и текущую активность пользователя в системе.

В зависимости от настроек системы, используемых механизмов аутентификации и предоставленных прав доступа полнота собираемой информации может различаться.

**Функционал инструмента/утилиты включает:**
1.	Запрос ввода логина пользователя (локального или доменного).
2.	Проверка, что у пользователя присутствует возможность на вход в оболочку/систему. (поиск по значению shell, удовлетворяющему маске «/bin/*.*sh»)
3.	Вывод основной информации о пользователе, а именно:
•	Логин для входа;
•	UID пользователя;
•	GID пользователя;
•	Полное имя (из GECOS);
•	Путь домашней директории;
•	Оболочка для входа;
•	Список групп (по имени), в которые входит пользователь. Включает как локальные, так и доменные группы.
•	Статус — заблокирован или не заблокирован.
4.	Вывод даты и времени последнего входа в систему пользователя.
5.	Вывод суммарного размера (в human-readable формате) домашней директории пользователя.
6.	Вывод ТОП-10 самых больших файлов в домашней директории пользователя, с указанием размера и полного пути к ним.
7.	Вывод списка файлов в домашней директории пользователя, где он (пользователь) не является их владельцем. Указывать реального владельца файла.
8.	Вывод ТОП-5 команд (по частоте использования), которые были выполнены пользователем в командной оболочки (из .bash_history).
9.	ТОП-5 процессов (по потреблению памяти), запущенных от пользователя с указанием: имя процесса, PID/TGID процесса, потребляемая память, потребляемое процессорное время.
